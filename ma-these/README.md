## Comment utiliser ce repo pour ta thèse

Ce repo contient 4 skills puissants :

### 1. deep-research (recherche bibliographique)
C'est ton point de départ. Pour ta revue de littérature :

```
/ars-lit-review "disparités régionales développement agricole Afrique de l'Ouest convergence"
/ars-lit-review "déterminants disparités agricoles spatial econometrics Burkina Faso"
/ars-lit-review "politiques agricoles et inégalités régionales productivité"
```

Modes disponibles :
- `socratic` : "Guide ma recherche sur les disparités régionales agricoles" -> dialogue de 20-30 tours pour affiner ta question
- `systematic-review` : revue PRISMA complète avec protocole
- `quick` : brief rapide pour un concept

### 2. academic-paper (rédaction)
Pour chaque essai :

```
/ars-plan -> pour planifier chapitre par chapitre avec mentor socratique
"Write a paper on regional convergence of agricultural productivity in Burkina Faso"
```

- Mode `plan` : recommandé pour doctorat - te guide chapitre par chapitre sans écrire à ta place
- Mode `outline-only` : génère juste le plan détaillé
- Mode `lit-review` : article de revue de littérature

### 3. academic-paper-reviewer (relecture critique)
Avant d'envoyer à ton directeur :

```
"Review this paper" + ton chapitre
```

5 perspectives : originalité, rigueur méthodo, suffisance des preuves, cohérence argumentaire, qualité rédactionnelle + Devil's Advocate qui attaque ta thèse.

### 4. academic-pipeline (orchestrateur complet)
Pipeline 10 étapes : RESEARCH -> WRITE -> INTEGRITY CHECK -> REVIEW -> REVISE -> FINALIZE

```
"I want to write a complete research paper on regional agricultural disparities determinants"
```
